# Function : [[FunctionBase]]

A Function is a named, reusable piece of script logic. It takes some inputs (its parameters), runs its steps, and can hand back a result. Functions let you write a behaviour once and then call it by name wherever you need it, instead of repeating the same script. Compare this with a [[Lambda]], which is a small unnamed function written inline where it's used.
