# StatScaling : [[Any]]

A StatScaling describes how an effect grows with one of a character's [[Stat]]s. It pairs a stat with a multiplier, letting a [[CombatEffect]] add extra damage or healing based on, say, the user's Strength. It is what [[CombatEffect#^scaleddamage1022549120\|ScaledDamage()]] uses to work out the final amount.
