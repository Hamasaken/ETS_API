# Vector2D : [[Any]]

A Vector2D is a pair of numbers describing a point or direction on a flat plane — an `x` (across) and a `y` (up/down) value together. It's used for two-dimensional positions and offsets, such as a spot on the screen or a direction in the game world. For grid squares specifically, [[GridItem]] is usually what you'll work with instead.
