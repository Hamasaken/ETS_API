# GridItem : [[Any]]

A GridItem is anything that sits at a spot on the combat grid, identified by its column (`x`) and row (`y`). It's the shared base for things on the map that have a position — both [[Tile]]s and [[Unit]]s build on it — so wherever you have a GridItem you can read where it is on the map.
