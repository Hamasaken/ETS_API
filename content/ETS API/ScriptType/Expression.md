# Expression : [[Any]]

An Expression is a piece of script that works out a value — a calculation, a comparison, or a lookup such as `u.IsEnemy(t)` or `str + 2`. It's the engine's internal representation of that logic. You write expressions as text inside asset files and scripts; you rarely handle the Expression type itself.
