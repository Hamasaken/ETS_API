# Scope : [[Any]]

A Scope is the surrounding area a script runs in — it holds the variables and functions available at that point. Inner scopes (such as inside a loop or a [[Lambda]]) can also see the values around them, and the outermost one is the Global scope. It's mostly an engine concept; as a content creator you feel it through which variables are within reach at a given place in a script.
