# Vector3D : [[Any]]

A Vector3D is a trio of numbers describing a point or direction in 3D space — an `x`, a `y` and a `z` value together. It's used for positions and offsets in the three-dimensional game world, such as where something sits or which way it faces. Like [[Vector2D]] but with the extra depth axis.
