# AttackType : [[ClassEnum]]

How a strike is delivered. Every [[Attack]] is one of these types, which combat rules and abilities can respond to — for example an effect that only triggers on Ranged attacks.

## Enum values
| Id  | Name    | Description |
| --- | ------- | ----------- |
| 0 | Melee  | A close-quarters strike. |
| 1 | Ranged  | An attack made from a distance. |
| 2 | Magical  | A spell-based attack. |
| 3 | Special  | An attack that doesn't fit the usual categories. |
