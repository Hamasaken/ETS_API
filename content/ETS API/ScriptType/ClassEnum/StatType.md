# StatType : [[ClassEnum]]

Every character in the game has a set of statistics that determines their gameplay characteristics.

## Enum values
| Id  | Name   | Default value | Description |
| ------ | ---------------------------------------- | ----- | ----- |
| 0 | [[StatType#^health\|Health]] | 10 | Hit points; the character is defeated when it reaches 0. |
| 1 | [[StatType#^mana\|Mana]] | 0 | The resource spent on abilities. |
| 2 | [[StatType#^speed\|Speed]] | 15 | Decides turn order in combat. |
| 3 | [[StatType#^movement\|Movement]] | 35 | How far the character can move each turn. |
| 4 | [[StatType#^actions\|Actions]] | 1 | How many actions the character gets per turn. |
| 10 | [[StatType#^defense\|Defense]] | 0 | Reduces incoming physical damage. |
| 11 | [[StatType#^resistance\|Resistance]] | 0 | Reduces incoming magical damage. |
| 12 | [[StatType#^accuracy\|Accuracy]] | 0 | Improves the chance of landing attacks. |
| 13 | [[StatType#^evasiveness\|Evasiveness]] | 0 | Improves the chance of dodging attacks. |
| 100 | [[StatType#^strength\|Strength]] | 0 | Physical power; boosts melee damage. |
| 101 | [[StatType#^dexterity\|Dexterity]] | 0 | Ranged power; also helps hit chance. |
| 102 | [[StatType#^intelligence\|Intelligence]] | 0 | Magical power and knowledge. |
| 103 | [[StatType#^constitution\|Constitution]] | 0 | Physical resilience and health. |
| 104 | [[StatType#^agility\|Agility]] | 0 | Evasiveness and speed. |
| 105 | [[StatType#^spirit\|Spirit]] | 0 | Magical resilience and mana. |
| 120 | [[StatType#^luck\|Luck]] | 50 | Affects events, loot and random rolls. |
| 121 | [[StatType#^charisma\|Charisma]] | 0 | Social influence. |
| 100000 | [[StatType#^sanity\|Sanity]] | 50 | The character's mental stability. |
| 100001 | [[StatType#^schlong size\|Schlong size]] | 50 | A novelty character stat. |
