# DamageType : [[ClassEnum]]

The damage in [[ETS API/Endless Tides]] can have several different elemental types. Certain characters might have immunities or weaknesses to specific damage types, and other effects might depend on them as well.


## Enum values
| Id  | Name    | Description |
| --- | --- | --- |
| 0 | Void  | Untyped, generic damage. |
| 1 | Physical  | Ordinary physical harm. |
| 2 | Fire  | Burning, flame damage. |
| 3 | Frost  | Cold and ice damage. |
| 4 | Nature  | Poison and natural damage. |
| 5 | Holy  | Radiant, divine damage. |
| 6 | Necrotic  | Death and decay damage. |
| 7 | Electric  | Lightning damage. |
