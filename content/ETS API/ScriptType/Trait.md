# Trait : [[EventAware]]

A Trait is one characteristic attached to a [[Character]] or [[Item]] — such as Undead, Consumable, or Flammable. Each trait belongs to a [[TraitGroup]] and can run effects when it is applied or removed. Traits are how characters and items gain special properties, and how scripts test for them.
